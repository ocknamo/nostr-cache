## 基本コンセプト

ストレージとトランスポートをアダプタとして差し替えることで、同一のリレーコアを
ブラウザ（IndexedDB + WebSocket エミュレータ）と Node.js（fake-indexeddb /
`node:sqlite` + `ws`）の両方で動かす。
